# BarProbe

An Android barcode toolkit for functionality testing, security testing, and
configuration. This site is the reference and guides; the source and releases live on
[GitHub](https://github.com/ryarmst/BarProbe).

## Guides

The **Learn** section explains the ideas that cause most barcode trouble — that payloads
are bytes rather than text, how to choose a symbology, character encodings and ECI, GS1
structure, check digits, and what makes a barcode actually scan. These are the same
articles shown inside the app.

## Reference

The **Reference** section is generated from the app's own symbology registry, so the
supported formats, character sets, length rules and escape syntax listed here match
exactly what the app will encode.
